# Question

ที่เก็บกฎและบันทึกสำหรับให้ Claude ตอบข้อสอบ/โจทย์ให้แม่นยำ

- `CLAUDE.md`: กฎการตอบ การประหยัดโทเคน และขั้นตอนเรียนรู้จากข้อผิดพลาด (Claude อ่านอัตโนมัติ)
- `notes/subjects/<วิชา>.md`: กฎเฉพาะวิชา · `notes/mistakes.md`: กฎรวมทุกวิชา
- `notes/log/<วิชา>.md`: บันทึกข้อที่เคยผิด · `notes/pending.md`: ข้อที่รอเฉลย · `notes/stats.md`: สถิติความแม่น

**วิธีใช้:** ส่งโจทย์ (ข้อความหรือรูป) มาได้เลย ถ้าคำตอบไม่ตรงเฉลย ให้บอกเฉลยที่ถูก แล้ว Claude จะบันทึกสาเหตุลงไฟล์นี้และใช้ในครั้งต่อไป
